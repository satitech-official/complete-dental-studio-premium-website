# Image Replacement Guide

This folder contains project-local visual assets.

- `instagram-profile.jpg`: public Instagram profile image from `@complete_dental_studio`, used as the clinic logo/avatar.
- `real-dental-operatory.jpg`: real dental operatory photo used for hero and clinic sections.
- `real-treatment-room.jpg`: real dental treatment-room photo used for page heroes and clinic sections.
- `gallery-*.jpg`: optimized gallery images used for before-and-after references, implant education, whitening process visuals, and clinic photo cards.

No generated placeholder images are bundled in this folder.

Recommended production replacements:

- Use original Complete Dental Studio clinic photos where available.
- Replace reference before-and-after images only with verified patient media after written consent and clinical approval.
- Use WebP or AVIF where possible.
- Keep descriptive file names such as `clinic-reception.webp`, `doctor-nikita-rawat-jain.webp`, and `treatment-room.webp`.
- Keep image dimensions stable to prevent layout shift.
- Update alt text in the relevant components when replacing imagery.

See `ATTRIBUTION.md` for source notes.
